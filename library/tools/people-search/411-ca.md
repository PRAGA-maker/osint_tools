# 411.ca

> Canada's white-pages directory — forward and reverse lookups tying a Canadian name, phone and address together.

## When to use
You have a Canadian subject and a `name`, `phone`, or `address`, and want the corresponding directory record. Use forward search (name → address/phone), reverse phone (number → listed owner), or reverse address (address → occupant/business). A solid free first step for locating or corroborating a Canadian person or business.

## How to use it (`bestInteractionPattern`: web-manual)
1. Open https://411.ca (or canada411.ca).
2. Pick the search mode: person, business, reverse phone, or reverse address.
3. Enter the selector — a 10-digit number for a specific reverse-phone listing, or name + city/province for a person.
4. Read the listing: full name, address, listed phone, and nearby/business matches.
5. Pivot: an `address` feeds property and neighbour lookups; a confirmed name feeds Canadian people-search and social enumeration.

## Inputs → Outputs
- **In:** `name`, `phone`, or `address`
- **Out:** `address`, `phone`, listed `name`
- **Empty/negative result looks like:** no listing — very common for mobile-only, young, or unlisted individuals, since directory data skews to landlines/businesses. Absence is not disproof of residence.

## Gotchas & OpSec
- Coverage is directory-grade: strong on listed landlines/businesses, weak on mobiles and unlisted people.
- Data can lag actual moves; corroborate a current address before relying on it.
- OpSec: fully passive, no login, no subject notification.

## Overlaps ("do both")
- Pairs with `[[switchboard]]` (US) and `[[melissa-com]]` — 411.ca covers Canada where US brokers are thin; run the matching country's directory.

## Trust & verifiability
`trust: community` — an established Canadian directory built on telco/business listing data; reliable for what it lists, but confirm currency for anyone likely to be mobile-only or recently moved.

# Security in a Box

> A free, multilingual digital-security handbook from Tactical Tech and Front Line Defenders. Not a data source — it's how an investigator (or their source) learns to stay safe.

## When to use
When you need to harden your **own** operational security or advise a vulnerable source before doing risky work: secure communications, protecting devices and data, safe use of social media, circumventing censorship, and maintaining anonymity. Reach for it to turn "I should be careful" into concrete, vetted steps. Especially relevant before engaging hostile targets or handling sensitive personal data in an investigation.

## How to use it (`bestInteractionPattern`: web-manual)
1. Go to securityinabox.org and pick your language.
2. Browse the guides by need — e.g. secure messaging, device encryption, strong passwords, safe browsing, protecting information from physical threats.
3. Follow the step-by-step, tool-specific instructions to implement a practice.
4. Apply relevant tactics to your investigation setup (and share source-facing guidance with at-risk contacts).
5. Combine with tool sources like `[[guardian-project]]` for the software the guides recommend.

## Inputs → Outputs
- **In:** none (guidance, not a selector lookup)

## Gotchas & OpSec
- It's defensive knowledge for you/your sources, not an investigative tool.
- Security advice ages — verify a recommended tool is still maintained and current before relying on it.
- Match tactics to your threat model; over- or under-protecting both carry costs.

## Overlaps ("do both")
- Complements `[[guardian-project]]` (the tools) and other OpSec/browser-hardening entries — Security in a Box explains the *practices*, those provide the *software*.

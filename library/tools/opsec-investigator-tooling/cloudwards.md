# Cloudwards

> Independent review-and-comparison site for privacy/security tooling — use it to pick the VPN, cloud storage or password manager that backs your investigator OpSec, not to look up a person.

## When to use
You are setting up or refreshing your own operational security — a VPN for sock-puppet browsing, encrypted cloud storage for case files, a password manager for burner accounts — and want independent, test-backed comparisons instead of vendor marketing. This is a tradecraft-support reference, not a selector-driven lookup tool; it returns no data about a subject.

## How to use it (`bestInteractionPattern`: web-manual)
1. Open https://www.cloudwards.net/ and pick the category (VPN, cloud storage, cloud backup, password managers, antivirus).
2. Read the comparison tables and the "how we tested" methodology; prefer the raw speed/feature numbers over the ranked "best" badge, which is affiliate-influenced.
3. Cross-check any pick against a second independent source before committing — a VPN choice is an OpSec decision.
4. Pivot: apply the chosen tool to harden the browser/identity you use with active tools like `[[account-live-com]]`.

## Inputs → Outputs
- **In:** none (topic/category browsing)
- **Out:** reviews, comparison tables, speed-test data, buying guides
- **Empty/negative result looks like:** a category with only sponsored roundups and no methodology section — treat those pages as advertising, not evaluation.

## Gotchas & OpSec
- Human-in-the-loop: none; it is a reading site.
- OpSec: passive — you leak nothing to any subject. The real risk is trusting an affiliate-ranked "#1" over your own threat model; read the test data, not the badge.

## Overlaps ("do both")
- Complements any active-interaction tool in this category (e.g. `[[account-live-com]]`) because those touch a target's infrastructure and depend on the VPN/identity hygiene this site helps you choose.

## Trust & verifiability

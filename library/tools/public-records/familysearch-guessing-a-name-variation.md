# FamilySearch – Guessing a Name Variation

> A methodology reference, not a database: how to generate the alternate spellings, nicknames, and transliterations of a name so your record searches stop missing the person.

## When to use
A `name` search is coming up empty or you suspect records exist under a different form of the name — a misspelling, a maiden name, an anglicised or transliterated version, a nickname, or an OCR error in an old index. This FamilySearch Research Wiki page teaches how to systematically brainstorm those variants (phonetic swaps, dropped/added letters, cultural naming conventions, common nickname↔legal-name pairs) so you can re-run searches with the right alternates. It's a thinking aid that makes every *other* name-based tool work better.

## How to use it (`bestInteractionPattern`: web-manual)
1. Open https://www.familysearch.org/wiki/en/Guessing_a_Name_Variation.
2. Read the techniques: phonetic variation, spelling variants, nicknames and diminutives, transliteration/anglicisation, and indexing/OCR errors.
3. Apply them to your subject's `name` to build a list of plausible alternate forms.
4. Re-run your record, genealogy, and people searches against each variant.
5. Pivot: the generated `name` variants feed FamilySearch's own record databases and any other name-driven tool (voter, court, social, obituary searches).

## Inputs → Outputs
- **In:** `name` (a name that's under-returning)
- **Out:** a set of alternate `name` forms (spellings, nicknames, transliterations) to search with
- **Empty/negative result looks like:** N/A — it's a reference article, always available. The "failure" is downstream: variants you generate still return nothing, which suggests the record isn't indexed under any obvious form.

## Gotchas & OpSec
- It is guidance, not a search engine — it produces ideas, not records; you still run the searches elsewhere.
- Don't over-generate: too many loose variants create false matches. Prioritise phonetically/culturally plausible forms.
- OpSec: fully passive; reading a wiki page touches nothing related to the subject.

## Overlaps ("do both")

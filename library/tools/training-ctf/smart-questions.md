# How To Ask Questions The Smart Way

> The canonical essay on framing questions so technical communities help you — a tradecraft reference, not a data source.

## When to use
You are about to ask a forum, mailing list, Discord, or subject-matter expert for help on an investigation and want the request to land — precise, self-contained, showing your own prior effort. Read this when a case stalls and you need outside expertise: it teaches how to state what you tried, what you observed, and exactly what you need, which is the difference between a useful answer and being ignored.

## How to use it (`bestInteractionPattern`: web-manual)
1. Open https://www.catb.org/esr/faqs/smart-questions.html.
2. Skim the section headings — "Before You Ask," "When You Ask," "How To Interpret Answers."
3. Before posting any request for help, run its checklist: search first, pick the right forum, write a specific subject line, describe symptoms and what you already tried, and avoid vague "it doesn't work" framing.
4. Apply the same discipline to prompts you give tools and models — a well-scoped question yields a well-scoped answer.

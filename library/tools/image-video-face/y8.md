# Y8

> A long-running free browser-games portal with public member profiles — useful only as a niche username pivot: does this handle have a Y8 account, and what avatar/activity does it show?

## When to use
You have a gaming `username` and want to check whether it is taken on Y8's community, where members have public profiles (avatar, favourite games, activity, sometimes a display `name`). A hit contributes an avatar image and a small behavioural footprint; a miss is cheap. This is a low-to-moderate signal step best run as part of a broad username sweep, not on its own.

## How to use it (`bestInteractionPattern`: web-manual)
1. Go to https://www.y8.com and use the site search, or navigate to the member/profile area, to look up the candidate `username`.
2. If a member profile exists, read the public fields: avatar `image`, display `name`, favourited games, and activity.
3. No login is needed to view a public profile — stay logged out.
4. Pivot: run the avatar through reverse-image search; carry the confirmed handle into `[[whatsmyname-web]]`/`[[namechk-2]]` to see where else it appears.

## Inputs → Outputs
- **In:** a gaming `username` (or display `name`)
- **Out:** public Y8 `social-profile`, avatar `image`, and light activity/interest signals
- **Empty/negative result looks like:** no member matches the handle — common and low-information, since Y8 is a niche community.

## Gotchas & OpSec
- Human-in-the-loop: none for viewing public profiles.
- OpSec: passive while browsing; it becomes active only if you register and follow/message. Don't authenticate with a real identity.
- Weak identity signal — profile fields are self-declared and a handle collision does not confirm it is your subject. Corroborate with the avatar and cross-platform handle matches.

## Overlaps ("do both")
- Run alongside `[[whatsmyname-web]]` and `[[namechk-2]]`, which test the same username across hundreds of sites at once and will usually surface stronger platforms; use Y8 to confirm a specific gaming-community hit.
- Pairs with `[[zynga]]` as another gaming-platform handle check.

## Trust & verifiability
`trust: unverified` — Y8 is a real portal with genuine public profiles, but the data is self-declared and the OSINT value is niche. Treat a match as a lead to corroborate, not as identity proof.

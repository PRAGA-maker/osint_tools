# awesome-security

> A big curated index of security tooling and resources — the place to browse when you know the *kind* of tool you need but not which one.

## When to use
You're not looking up a subject — you're looking for a **tool or resource** and want a curated starting point. awesome-security groups scanners, threat-intel sources, DFIR tools, network utilities, and learning material by topic, so it's useful for discovering options and filling gaps in your toolkit. Reach for it at the "what should I use for X?" stage, not during active collection.

## How to use it (`bestInteractionPattern`: web-manual)
1. Open https://github.com/sbilly/awesome-security.
2. Use the README's table of contents to jump to the relevant category (network, DFIR, threat intelligence, etc.).
3. Scan the entries and pick candidates; follow through to each tool's own page to confirm it's current and fits.
4. Vet before adopting — an awesome-list entry is a lead, not a guarantee the tool is maintained or safe.

## Inputs → Outputs
- **In:** none (a reference index — you browse by topic)
- **Out:** none as selectors — a shortlist of tools/resources to evaluate
- **Empty/negative result looks like:** no entry for your niche, or entries that are stale/abandoned — cross-check with other awesome lists and confirm each tool independently.

## Gotchas & OpSec
- **Curated ≠ vetted or current** — some links rot or point to unmaintained projects; verify each tool yourself.
- It's discovery, not capability — the value is in the tools it points to, so budget time to evaluate them.
- Fully passive reference.

## Overlaps ("do both")
- One of many "awesome-*" indexes (awesome-osint, awesome-threat-intelligence, etc.) — consult several, since coverage differs and a tool missing from one often appears in another.

## Trust & verifiability
`trust: community` — a well-known community-maintained list; reliable as a map of the landscape, but every destination it points to needs its own verification.

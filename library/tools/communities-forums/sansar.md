# Sansar

> A social-VR world (avatars, live events, user-built spaces) — a place to trace a subject's virtual persona and the community they move in.

## When to use
A niche resource for cases with a virtual-world/gaming angle. If a subject uses a `username` associated with Sansar, you can look for their avatar/profile, the events they attend, and the worlds/people they interact with — useful for building out an online-persona map or linking a handle across platforms. Real-identity links are inferential, so treat it as persona intelligence, not identification.

## How to use it (`bestInteractionPattern`: desktop-app)
1. Create a sock-puppet Sansar account and install the client (free).
2. Search for the `username`/avatar name, or attend public events/worlds where the persona is active.
3. Observe the profile, avatar appearance, and social connections (`associate`) — who they gather with.
4. Stay passive: don't voice-chat, friend, or interact in a way that reveals your interest.
5. Pivot: the handle feeds cross-platform username search; avatar style/voice and named associates are leads; a linked external profile confirms the persona.

## Inputs → Outputs
- **In:** `username`/persona name
- **Out:** Sansar `social-profile`/avatar and community `associate`s
- **Empty/negative result looks like:** no persona found — the subject isn't on Sansar under that handle, or uses a different one; VR personas are deliberately pseudonymous, so absence tells you little.

## Gotchas & OpSec
- **Pseudonymous by design** — connecting a Sansar avatar to a real person requires external corroboration; don't over-attribute.
- OpSec is **active**: you must enter the world with a visible avatar; use a sock puppet and observe, never engage.
- Requires the desktop client and an account; it's a live 3D environment, not a web lookup.

## Overlaps ("do both")
- Pairs with cross-platform username search and other gaming/VR-community tools (VRChat, Second Life) — a subject's VR persona often spans platforms, so run the handle across them.

## Trust & verifiability
`trust: community` — the platform is genuine, but personas are self-created and pseudonymous, so any real-world link is a hypothesis to confirm with independent evidence.

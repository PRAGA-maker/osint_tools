## When to use

This list gathers data-journalism tooling in one place; use it to discover a dataset or method, then apply it. It's a discovery layer with lower direct relevance to person-finding.

## How to use it (`bestInteractionPattern`: web-manual)
1. Open https://github.com/r3mlab/datajournalism-resources.
2. Read the README's categorized links (datasets, tools, tutorials, references).

4. Check the repo's last-updated date to judge freshness before relying on a link.
5. Pivot: a dataset surfaces names/places/orgs → feed those into targeted people/records tools.

# IVMachiavelli OSINT Team Links

> A big, category-organized GitHub directory of OSINT tools and resources — a "what should I use for this?" index rather than a tool that returns data itself.

## When to use
Reach for this when you're stuck on *which* tool fits a task: a category of records, a country's registries, a class of social/username tools, image/geolocation resources, etc. The list groups hundreds of community-vetted links by purpose, so it's a fast way to find candidate tools for a gap in your workflow — then you evaluate and apply the specific one.

## How to use it (`bestInteractionPattern`: web-manual)
1. Open https://github.com/IVMachiavelli/OSINT_Team_Links and read the README (use the section outline / in-page search).
2. Jump to the category matching your need (e.g. usernames, breaches, geolocation, business records).
3. Follow candidate links out to their tools; **verify each is still live and reputable** — aggregator lists always contain some dead or changed entries.
4. Apply the chosen tool to your subject/selector.
5. Pivot: fold anything genuinely useful into your standing toolkit; use this list to fill gaps, not as a day-to-day query engine.

## Inputs → Outputs
- **In:** the *task/need* (which kind of OSINT tool you're looking for)
- **Out:** a categorized list of candidate tools/resources to evaluate — no subject data itself
- **Empty/negative result looks like:** a category with only dead or irrelevant links; fall back to other awesome-OSINT lists or this library's own indexed tools.

## Gotchas & OpSec
- **Directory, not an engine** — it points you at tools; it doesn't do the lookup.
- Link rot: some entries are stale or have changed hands — confirm each destination before trusting it.
- Community-curated: quality varies per link; vet reputation, especially for anything handling breach/PII data.

## Overlaps ("do both")
- Pairs with other curated OSINT directories and this library itself — cross-reference multiple lists, since each surfaces tools the others miss.

## Trust & verifiability
`trust: community` — a well-established, actively-maintained community list; trustworthy as an index, but the responsibility to verify each linked tool's current status and reputation is yours.

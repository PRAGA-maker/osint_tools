# OSINT-Cheat-sheet

> A community-curated GitHub index of OSINT tools, wikis, datasets, and techniques — a discovery reference for widening your toolset when the tools you know run out.

## When to use
You're stuck on a selector and want to know what *else* exists — additional people-search sites, a niche dataset, a geolocation technique, a country-specific resource. This is a reference list, not a lookup tool: read it to find candidate tools and methods to try, then go use those. Best treated as a frontier to mine for new tooling (some of which may be worth adding to this very library), not as something that returns data on a subject.

## How to use it (`bestInteractionPattern`: web-manual)
1. Open https://github.com/Jieyab89/OSINT-Cheat-sheet.
2. Use the README's category headings (people, social media, geolocation, domains, etc.) or GitHub's in-page find to jump to the area you need.
3. Scan the listed tools/datasets and open the ones that fit your current selector.
4. Read the output: a shortlist of candidate resources — go run those against your actual case.
5. Pivot: each linked tool is the real next step; verify it's live and free before relying on it (cheat-sheet links rot over time).

## Inputs → Outputs
- **In:** none (a browsable reference, not a query interface)
- **Out:** pointers to other tools/datasets/techniques by category — no direct data on a subject
- **Empty/negative result looks like:** the category you need is thin or the links are dead — treat it as one index among several (cross-reference other "awesome-OSINT" lists).

## Gotchas & OpSec
- Human-in-the-loop: none to read it.
- OpSec: passive; the OpSec that matters attaches to the downstream tools you pick, not to this list.
- Link rot: as with any awesome-list, some entries are stale or point to defunct/paid tools — verify each before use.

## Overlaps ("do both")
- Redundant with other curated OSINT directories (awesome-osint, OSINT Framework) — consult more than one, since each indexes a different slice and none is complete or fully current.

## Trust & verifiability
`trust: community` — a single-maintainer curated list; helpful for discovery but unvetted, so confirm any tool it names is live, free, and appropriate before you act on it.
